## 🚀 Proyectos destacados

### 🎮 [GameDeck](https://github.com/vicenttto/GameDeck)
Plataforma web para centralizar tu colección de videojuegos repartida entre Steam, PlayStation, Nintendo, Epic/GOG, etc. **Trabajo de Fin de Ciclo (DAW)**, desarrollado junto a [@gzbl-dev](https://github.com/gzbl-dev).

- 🔐 Autenticación JWT, biblioteca personal con 6 estados de backlog, reseñas y funciones sociales (seguir usuarios, feed de actividad)
- 🔎 Integración con la API de [RAWG.io](https://rawg.io/apidocs) para carátulas y metadatos automáticos de juegos
- 🛡️ Panel de administración, base de datos versionada con Flyway (10 tablas)

`React 18` `TypeScript` `Vite` · `Java 21` `Spring Boot` `Spring Security` · `MySQL`

🔗 **Demo**: [gamedeck-tfg.vercel.app](https://gamedeck-tfg.vercel.app)

### 🍽️ [Murcia, desde su Sabor](https://github.com/vicenttto/murcia-desde-su-sabor)
Web multipágina para una iniciativa gastronómica real del **Ayuntamiento de Murcia** (Servicio de Turismo): catas, ciclos gastronómicos y talleres en la Región de Murcia.

- 🌗 Modo claro/oscuro persistente, animaciones scroll-reveal y diseño totalmente responsive
- 🎟️ Sistema de eventos con tickets (filtros, estado disponible/agotado)
- ✉️ Formulario de contacto con validación, honeypot anti-bots y rate limiting en el backend PHP

`HTML` `CSS` `JavaScript` `Tailwind CSS` · `PHP`

🔗 **Demo**: [vicenttto.github.io/murcia-desde-su-sabor](https://vicenttto.github.io/murcia-desde-su-sabor/)
